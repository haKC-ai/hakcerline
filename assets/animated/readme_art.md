# hakcerline Animated Logos

Animated transparent-background GIFs of the hakcerline ASCII banner, rendered using every [terminaltexteffects](https://pypi.org/project/terminaltexteffects/) effect.

**29 effects** · **40 frames each** · **60ms/frame** · **Transparent RGBA background**

Click any animation to open the full GIF.
